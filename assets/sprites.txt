// Clawd sprites, 2x detail (each body is 32 px wide). Format (PLAN.md §6):
//   @frame <name> [anchor=x,y] [eyes=x,y;x,y] [hold=n] [mirror=no]   followed by pixel rows
//   @anim <name> fps=<n> loop|once [eyes=<style>] [glyph=<g>] [frames=a,b,...]
//   @step <body> [eyes=<style>] [look=dx,dy] [dy=n] [fx=a+b] [glyph=<g>] [hold=n]
// Lines starting with // are comments. Every row of a frame has the same width.
//
// Style: light from the top-left; body tones h (specular) L O D E (deep
// shadow); R = rust outline around the body; P = blush. Props and the bubble
// are outlined with K.
//
// Rig (PLAN.md §6b): body frames are drawn WITHOUT eyes. `eyes=` lists the
// eye anchors (left eye first; x is the eye's centre line, a pixel boundary
// like the feet anchor); the eye sprite `eye_<style>` is drawn there,
// its own anchor on the eye anchor, mirrored for the right eye unless the eye
// frame says mirror=no (eyes whose shine must stay on the lit side).
// - Body anchor = the point between the feet on the bottom row (x is a pixel
//   boundary, so x=16 is the centre line of a 32-wide frame).
// - fx frames (props, particles) use the same anchor convention: their anchor
//   is where the body's feet point falls in the fx frame's coordinates, so
//   they move and flip with the body. Negative anchors are fine.
// - glyph=<g> shows `glyph_<g>` in the speech bubble; `none` turns a layer off.
// - Steps last `hold` ticks of 1000/fps ms. Anims default to eyes=normal.
//
// The body frames were generated from parts (box, arms, legs) so every pose
// shares the same shading; edit them by hand from here on.
